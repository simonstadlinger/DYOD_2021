# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately via GitHub's private vulnerability reporting:
go to the **Security** tab of this repository and click **"Report a vulnerability"**,
or use this repository's `/security/advisories/new` URL.

You should receive a response within 5 business days. Please include as much of
the following information as possible to help us understand and resolve the
issue quickly:

- Type of issue and its impact
- Affected file(s) or component(s)
- Steps to reproduce the issue

## Supported Versions

Only the latest version on the default branch is supported with security updates.
